# RioJunior - Painél Estratégico

faça uso do código no documento acima para recriar a ideia de um sistema para a RioJunior
a ideia é fazer um sistema de gestão estratégica para as 5 diretorias da Federação de Empresas Juniores do Estado do Rio de Janeiro (RioJunior):
Presidência Executiva
Vice-Presidência de Negócios
Operações
Desenvolvimento da Rede
Formação Empreendedora

no código temos uma primeira aba com a calendarização da RioJunior, com uma opção de selecionar eventos colocando nome, tipo de evento, data, pauta/tema e principais Diretorias responsáveis e depois conseguimos ver esses eventos no calendário
Também temos uma aba de DDR (Diretoria de Desenvolvimento da Rede) com os dados das nossas EJs (Empresas Juniores):

Nome
Região (Norte; Centro Norte; Centro Sul 1; Centro Sul 2; Sul)
Cluster (Nível de maturidade - de 1 a 5)
Localização
Faturamento com base na meta anual (e seu destrinchamento em intervalos de tempo)
CNPJ

Dentro de Operações terão dados relacionados ao caixa da RioJunior, controle de entradas e saídas, além de um planejamento financeiro com projeção de entradas e saídas
As outras Diretorias iremos construir depois
