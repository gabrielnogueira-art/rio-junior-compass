# Pasta de Logos das Empresas Juniores - RioJunior DDR

Esta pasta contém as imagens de logo de cada Empresa Júnior da Federação RioJunior.

## Como Nomear os Arquivos
Você pode colocar os arquivos de imagem das logos nesta pasta nos formatos PNG ou SVG.
O nome do arquivo deve corresponder ao slug da EJ:
Exemplo:
- formula-consultoria.png
- ceta-jr.png
- poli-junior.png
- cefet-jr.png
- fluxo-consultoria.png

Caso alguma logo ainda não tenha sido adicionada, o sistema gera automaticamente um monograma elegante personalizado com a paleta de cores do Cluster da EJ.
